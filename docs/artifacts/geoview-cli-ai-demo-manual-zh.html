🧭 GeoView CLI / AI 助手 — 功能总结与演示手册

分支 feature/cli-foundation（13 commits）。在运行的 GeoView 里用 --cli 跑脚本化命令，或用 in-app AI 聊天用自然语言驱动同一套命令。

架构一句话：所有能力是注册到一个命令表（HrsCliCommandRegistry）的命令；同一套命令被三个前端复用——命令行 --cli、应用内 AI 聊天、（未来）Python。命令通过抽象层（seam）访问 GeoView 数据，所以核心库不依赖 Qt、可单测。

1已实现的命令

项目 / 导航

  • open project 加载工程并保持窗口交互
  • list projects 列目录下的 .prj
  • describe project wells / volumes / horizons 计数

井 (well)

  • list wells
  • describe well --well W logs + depth range + tops
  • stats well --well W --log L min/max/mean/median/p10/p90 + 缺失率 + 深度
  • compare logs --well W --logs "L1,L2,…" 多 log 并排对比

体 (volume)

  • list volumes
  • describe volume --volume V inline/xline 范围、samples、domain
  • stats volume --volume V [--exact] 估算或全量扫描；--exact 加百分位+直方图
  • stats volume --inline-min/-max … inline/xline/domain 区域统计
  • spectrum volume --volume V 平均振幅谱 + 主频/带宽 + AI Bandpass 建议

可视化

  • show seismic --volume V --inline N 打开剖面窗口（保持交互）
  • render seismic --volume V --inline N --out png 导出剖面截图

AI 助手

  • chat "自然语言问题" LLM 工具调用循环驱动上面的命令
  • 本地 Ollama ↔ Claude 可切换；异步（不卡 UI）；Preferences 可配模型/端点

Help RAG（文档问答）

  • help.index --dir <help> --out idx [--max N] 嵌入 help HTML 建索引
  • help.ask --question "…" [--index idx] 检索 + LLM 答 + 来源引用

2怎么跑 CLI 命令行

GeoView 是 GUI 子系统进程（无自带控制台、shell 不等待），所以脚本化时：查询结果写到 --out 文件，跑完读它；需要工程的命令带 --dir + --name。PowerShell 用单字符串 ArgumentList，给含空格的参数（如项目名）加引号：

# 通用模板
$exe = "...\hrs\build\bin\win64\vs2022\hrs\Debug\geoview.exe"
Start-Process -FilePath $exe -Wait -ArgumentList '--cli stats volume --dir C:\test\ --name "GOM V3.prj" --volume AG_Spec_Bal --out C:\test\out.json'
Get-Content C:\test\out.json
路径约定：--dir C:\test\（带尾斜杠）+ --name "GOM V3.prj"（带 .prj、有空格必须引号）。
--out 例外：render seismic 的 --out 是 PNG 图片、help.index 的 --out 是索引文件——它们的 JSON 结果自动走默认文件，不会覆盖产物。

3怎么用 GUI 应用内

  1. 启动 GeoView（普通启动，或 --cli open project --dir … --name … 直接加载工程并保持交互）
  2. 右下角状态栏点 AI Assistant 按钮 → 弹出聊天框
  3. 输入自然语言问题（"how many wells"、"describe AG_Spec_Bal"、"suggest bandpass for AG_Spec_Bal"…）→ 异步回答，思考时输入框禁用、UI 不卡
  4. Backend 下拉：Local (Ollama) / Claude（后者需 ANTHROPIC_API_KEY，否则置灰）
  5. Settings… 按钮 → Preferences：改后端 / Ollama 端点 / Ollama 模型 / Claude 模型，持久保存、无需重启
  6. Help 问答：设好 GEOVIEW_HELP_INDEX 并重启后，聊天里问操作问题（"how do I import SEGY"）→ 从 967 篇 help 文档检索作答 + 引用来源

4端到端演示脚本（GOM V3）

把 $exe / $dn 设好后逐条跑；每条读对应 --out 文件看结果。

$exe = "...\geoview.exe"
# 工程概览 -> wells:4, volumes:18, horizons:7
... -ArgumentList '--cli describe project --dir C:\test\ --name "GOM V3.prj" --out C:\test\r.json'

# 体统计：估算（秒级）/ 精确（扫全量，加百分位+直方图）/ 区域（inline 14700-14750）
'--cli stats volume --dir C:\test\ --name "GOM V3.prj" --volume AG_Spec_Bal --out …'
'--cli stats volume … --volume AG_Spec_Bal --exact --out …'
'--cli stats volume … --volume AG_Spec_Bal --inline-min 14700 --inline-max 14750 --out …'

# 井：单 log 统计 / 多 log 对比
'--cli stats well … --well Well_1 --log "Gamma Ray" --out …'      # mean 90.7 gAPI
'--cli compare logs … --well Well_1 --logs "Gamma Ray,Resistivity,Density" --out …'

# 频谱 + AI Bandpass 建议
'--cli spectrum volume … --volume AG_Spec_Bal --out …'            # peak~5Hz, 建议 1.2/2.5/40/50Hz

# 截图导出（--out 是 PNG）
'--cli render seismic … --volume AG_Spec_Bal --inline 14700 --out C:\test\inline14700.png'

# AI 聊天（自然语言 -> 工具调用）
'--cli chat "how many wells are in this project" … --out …'      # "four wells"

# Help RAG 文档问答（--question；预加载或 --index）
'--cli help.ask --index C:\test\help_full.idx --question "how do I import a SEGY volume" --out …'

# GUI 交互：打开剖面 / 加载工程并保持窗口
'--cli show seismic … --volume AG_Spec_Bal --inline 14700'
'--cli open project --dir C:\test\ --name "GOM V3.prj"'           # 然后点 AI Assistant 按钮
小模型提示：聊天默认 gemma3:4b（小模型），工具调用偶尔把参数写歪——遇到换 Preferences 里的 qwen2.5 或 Claude 后端更稳。所有命令直接用 --cli 跑则总是可靠。
合规：默认本地 Ollama、数据不外发；Claude 是显式 opt-in，切换提示会警告勿用真实客户/受管数据；AI 给的处理参数（如 Bandpass）是建议、带"geophysicist review"提示，绝不自动改工程。
