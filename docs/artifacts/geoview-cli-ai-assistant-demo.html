Why it stands out

Five things worth demoing first

Each is grounded in real data on a real project — nothing is mocked.

Local-first

Your data stays on-prem

Defaults to a local Ollama model, so well and volume names, stats and logs never leave the machine. Claude is an explicit opt-in backend with a clear data-egress warning; the API key is read from the environment only — never hardcoded or persisted.

Deterministic routing

It doesn't rely on the model to guess

A GUI-free parser maps phrases like stats volume AG_Spec_Bal straight to the right command. The model only turns the JSON result into prose — so even small local models stay reliable.

Parameter advice

Data-driven processing suggestions

Bandpass, gather conditioning, scaling, deconvolution and AGC — each computed from the volume's own measured features, always flagged as a starting point for a geophysicist to review, never applied automatically.

Help RAG

Answers from the manual, with citations

Semantic Q&A over 967 help documents (5,042 indexed chunks). Ask “how do I import a SEGY volume” and get an answer that cites the source pages.

Responsive UI

Streaming, never frozen

Answers stream in as they generate and the window stays interactive while the model works. The model is kept warm between messages to avoid cold-reload stalls.

Capabilities

What you can ask it to do

One consistent command set, reachable three ways: the in-app chat popup, a one-shot CLI, or direct command phrases.

  • open project load a workspace and stay interactive
  • describe project wells / volumes / horizons at a glance
  • report project a readable Markdown QC report

Wells well

  • describe well logs, depth range, tops
  • stats well · compare logs per-curve statistics, side by side

Volumes volume

  • stats volume fast estimate or --exact full scan + percentiles
  • compare volumes sample-by-sample RMS & correlation
  • describe volume real geometry, no GUI needed

Imaging seismic

  • show seismic open a section and jump to an inline
  • render seismic write a PNG of the section
  • window screenshot capture the main window

Prestack gather

  • gather qc offset/angle range, fold, coverage + histogram
  • identifies prestack vs poststack automatically
  • rule-based conditioning hints included

Knowledge help

  • help ask semantic Q&A over the docs
  • help index build the embedding index
  • answers cite their source pages
The differentiator

AI processing-parameter suggestions

One reusable recipe — an analysis command that measures a real feature of the data, plus a transparent rule baseline. The AI layer narrates the numbers and always defers the final call to a geophysicist.

spectrum → Bandpass

Bandpass filter

Peak frequency and −6 dB band from an averaged amplitude spectrum.

gather qc → conditioning

Gather conditioning

Super-gather, infill and mute hints from fold, coverage and angle range.

stats → RMS

Scaling

A scaler from the measured RMS toward a target amplitude.

autocorr → operator

Deconvolution

Prediction gap and operator length from the trace autocorrelation.

envelope → window

AGC

Gain window sized to the energy-decay time of the RMS envelope.

Under the hood

Engineered to stay clean

Layering

GUI-free core + seams

The command library is pure std C++14 with no GUI dependency, bound to GeoView through two interfaces — a project data source and a seismic viewer — so command logic is unit-testable without the app.

Quality

Test-driven

173 unit tests across 28 suites; commands and the phrase parser were written test-first.

Proof

Verified on a real project

Exercised end-to-end on the GOM V3 survey — 4 wells, 18 volumes, 7 horizons — not synthetic fixtures.

Extensibility

A repeatable recipe

A new process needs only an analysis command and a rule baseline; the AI layer is reused unchanged.

Local by default, remote by explicit choice

The assistant runs against on-prem models unless someone deliberately switches to the remote backend, and even then it warns before project data is sent. That posture is what makes the tool safe to put in front of real interpreters.
