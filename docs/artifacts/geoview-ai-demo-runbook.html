⚙️Setup for cmd vs PowerShell

Define two shorthands once per terminal session, then every CLI line below just works.

cmd.exe
set GV="C:\sandbox\monorepo_cli\monorepo\hrs\build\bin\win64\vs2022\hrs\Debug\geoview.exe" set PROJ=--dir C:\test\ --name "AVO GOM Workshop.prj" --out C:\Users\sxing\r.json

Use (cmd re-tokenizes the text, so quotes are honored):

%GV% --cli stats volume --volume cdp_stack %PROJ%
PowerShell  (your default shell)
$GV = 'C:\sandbox\monorepo_cli\monorepo\hrs\build\bin\win64\vs2022\hrs\Debug\geoview.exe' $PROJ = '--dir','C:\test\','--name','AVO GOM Workshop.prj','--out','C:\Users\sxing\r.json'

Use the call operator & and splat the array with @PROJ:

& $GV --cli stats volume --volume cdp_stack @PROJ

Read the result:

Get-Content C:\Users\sxing\r.json
NL vs CLI. The NL lines are what you say in the AI Assistant popup — plain sentences, routed by the model (use qwen2.5:7b for reliable routing). The CLI lines are the exact, deterministic equivalents; the short command phrases (list wells, stats volume cdp_stack, describe well 01-08) also work verbatim in the chat and route without the model.
PowerShell notes. Use & to run an exe stored in a variable, and @PROJ (splat) so the array becomes separate args. Quote comma-lists (--logs 'P-wave,Density,S-wave_trans'). 'AVO GOM Workshop.prj' is one quoted token. Per-command CLI lines below are PowerShell; in cmd use %GV% … %PROJ%.
Four gotchas. (1) CLI-direct needs explicit flags. (2) Use an absolute --out. (3) Don’t run a volume-data CLI command while a GeoView holds the same project (file lock). (4) In the Bandpass dialog, close with Cancel, not “X”.
Every one-shot --cli launches GeoView (it’s a mode of the GUI app, not a headless binary): each command boots GeoView, runs, writes --out, exits (a window flashes). For a live demo don’t run one-shot commands repeatedly — start one open project session (it stays open) and drive everything from the chat popup. Reserve one-shot --cli for scripting.

🎚️AI parameter suggestions

Each = a real data measurement + a rule baseline; always “a starting point, review with a geophysicist,” never auto-applied.

Bandpass (from spectrum)volume.spectrum
Averaged amplitude spectrum → peak / −6 dB band → a suggested Bandpass filter.
NL

NL

CLI& $GV --cli spectrum volume --volume cdp_stack @PROJ

Scaler = target RMS / current RMS. Normalizes amplitude level for display / comparison (a single global gain).

CLI& $GV --cli scaling volume --volume cdp_stack --exact @PROJ
Deconvolutionvolume.decon

NL

CLI& $GV --cli decon volume --volume cdp_stack @PROJ
AGCvolume.agc
RMS envelope → gain window sized to the energy-decay time. Equalizes amplitude down the trace (for display).

CLI& $GV --cli agc volume --volume cdp_stack @PROJ
Gather conditioninggather.qc · hint
The conditioning hint (super-gather / infill / mute, from fold, coverage, angle range) is part of Gather QC's output — there is no separate command. Use the deterministic phrase below; the free-form question relies on the model and may hallucinate steps instead of calling the command.
NL
gather qc angle_gather
CLI& $GV --cli gather qc --volume angle_gather @PROJ
